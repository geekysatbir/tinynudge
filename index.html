What is an online mouse jiggler?

A mouse jiggler is anything that stops a computer from thinking you walked away: screen sleep, a lock screen, or a chat status flipping to Away. Hardware jigglers are USB dongles. Software jigglers are Mac or Windows apps. An online mouse jiggler is a webpage — the fastest option when you cannot install software.

Browsers are sandboxed. They can ask the operating system to keep the display on (the same idea as a YouTube tab). They cannot inject operating-system mouse events. If someone promises a website will move your cursor or keep desktop Slack green, that claim is stronger than the web platform allows. TinyNudge tells you the split up front.

Frequently asked questions

Does this online mouse jiggler move my real mouse?

No. The glowing cursor on the card is a preview. Your system pointer does not move. That is a browser security rule, not a missing feature.

Will Slack or Microsoft Teams stay green?

Desktop apps watch keyboard and mouse idle, not whether a tab holds a wake lock. This page keeps the screen awake. For status idle, download TinyNudge for Mac or use a hardware jiggler.

Do I need admin rights?

No. If you can open a website, you can run this mouse mover.

Does it work on Mac, Windows, and Chromebook?

Yes, in a modern browser. Wake Lock is most reliable in Chrome and Edge. Safari 16.4+ and recent Firefox are supported; the silent-audio fallback covers older gaps.

Is TinyNudge free?

The website is free. TinyNudge for Mac is $2.99 per year. One download runs on Apple Silicon and Intel Macs.

Is my data collected?

The jiggler runs locally in your browser. See the privacy policy. No account is required.
