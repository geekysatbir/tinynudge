TinyNudge for Mac

Menu-bar mouse jiggler — $2.99/year

The website keeps the display awake. The Mac app nudges the real pointer a few pixels and back, once a minute. One disk image for Apple Silicon and Intel. macOS 13 or later. Accessibility permission is required.

Use the contact form to request the disk image. We send a payment link, then the .dmg after you pay. Do not put card numbers in the form.

Install

  1. Open the disk image and drag TinyNudge to Applications.
  2. First launch: right-click the app → Open if macOS says the developer cannot be verified.
  3. System Settings → Privacy & Security → Accessibility → enable TinyNudge.
  4. Start and stop from the window or the menu-bar icon.
