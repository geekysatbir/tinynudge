Privacy policy

TinyNudge’s online mouse jiggler runs in your browser using the Screen Wake Lock API, optional silent audio, and optional Picture-in-Picture. Session state never leaves your device. We do not require an account, and we do not record mouse coordinates, keystrokes, or screen contents.

This static site may be hosted on GitHub Pages or Cloudflare. Those providers see normal web logs (IP address, user agent) as with any website. We do not run advertising or analytics scripts on this version. TinyNudge is not a tool for bypassing employer monitoring or security software.

This site does not use accounts, contact forms, or a public source-code link. The Mac app is distributed separately when checkout is available.
