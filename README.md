# TinyNudge

Free **online mouse jiggler** (keep the screen awake in the browser) plus a tiny **Mac menu-bar** app that actually nudges the pointer.

- Site: open `index.html` or serve this folder. Canonical domain: [mousejiggle.app](https://mousejiggle.app/) (buy the domain; this check did not reserve it).
- Mac: `dist/TinyNudge.dmg` — drag to Applications, right-click → Open, enable Accessibility, menu bar **TN** → Start.

The website does **not** move the system mouse. The Mac app does (3px and back, every 60s). It pauses a cycle if you move the mouse yourself.
